# Atelier Living Glass

Premium furniture and small-appliance website prototype built with React and Vite.

## Local Preview

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## GitHub Pages

This repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml`.
After the project is pushed to the `main` branch, GitHub Pages can publish the built site automatically from the workflow artifact.
